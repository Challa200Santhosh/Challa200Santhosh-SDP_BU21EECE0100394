## ▶️ How to open

- **8051 projects:** open the `.uvproj` file in Keil µVision, build, then load the generated `.hex` into the matching Proteus `.DSN` schematic and run the simulation.
- **Arduino programs:** open the `.c` file contents in the Arduino IDE and upload to an Arduino Uno.
